# AIFriends 产品需求与实施方案

版本：V1.1　核对日期：2026年10月10日　适用对象：产品、设计、开发、测试与部署负责人

本版替代 V1.0 的当前状态说明。依据当前源码、81项后端测试、9项前端测试、真实供应商调用和本地浏览器验收更新。用户确认本轮完成现有系统与 P0/P1，P2 保留规划。代码实现、本地验收与生产验收分别标注；本文不承诺尚未实测的供应商、设备和并发能力。

## 1 产品定位、用户与版本范围

AIFriends 是 AI 角色创作与对话平台。核心闭环为发现角色、建立好友关系、发起对话、保存历史、再次继续。创作者维护角色形象、公开介绍、私有设定、音色和知识文件。

| 用户 | 可以完成的操作 | 权限边界 |
|---|---|---|
| 游客 | 浏览和搜索已发布的公开角色 | 不读取私人设定、会话或音频 |
| 普通用户 | 账号、资料、好友、聊天、语音、记忆和举报 | 消息与记忆仅本人访问 |
| 创作者 | 上述能力以及角色、知识、个人音色、任务管理 | 仅修改自己的角色和资源 |
| 管理员 | Django admin 审核、举报处理、资源管理和健康接口 | staff 权限；审核处理留下审计记录 |

P0：账号、资料、角色创建编辑、草稿发布范围、发现搜索、好友、文字聊天、全文历史、停止重试、异常提示、基本部署。

P1：语音输入与回复、预设与个人音色、知识上传检索引用、长期记忆、持久化任务、审核举报、健康监测和恢复演练。

P2：收藏、标签筛选、推荐、分享产品流程、运营事件分析和统计看板。付费、群聊、视频通话、多会话切换、PDF/OCR 导入不在本轮范围。

## 2 功能现状与验收口径

“已实现并回归”表示代码和指定测试通过；“真实链路通过”表示本机当前账号的供应商调用成功；“待外部验收”表示仍需要外部配置或设备。通过不等于所有环境均可用。

| 模块 | 当前行为 | 本轮状态及边界 |
|---|---|---|
| 注册、登录、恢复、退出 | JWT、HttpOnly 刷新 Cookie、轮换及黑名单 | 回归通过；刷新创作页登录恢复顺序已修复 |
| 个人资料 | 用户名、介绍、头像更新与裁剪 | 回归通过；图片格式、内容、体积校验 |
| 角色创作 | 公开介绍与私有设定分离，可不选音色 | 浏览器创建、裁剪、发布和恢复通过 |

| 角色知识库 | TXT/MD上传、查重、异步索引、关键词检索、来源保存 | 浏览器真实知识问答和引用通过 |

| 长期记忆 | 查看、修改、清空、会话开关、乐观版本控制 | 浏览器保存/关闭/清空通过；自动摘要默认关闭 |
| 自动摘要 | 每10条成功对话入持久化任务；过期版本不覆盖 | 回归通过；尚未打开本地自动策略进行真实连续验收 |

| 数据恢复 | 升级前数据库及媒体备份，隔离副本迁移 | 完整性与旧内容一致性通过 |

## 3 信息架构与页面设计

| 页面 | 内容与主操作 | 状态要求 |
|---|---|---|
| 首页 | 角色卡片、搜索、加载更多、开始聊天 | 空结果、加载、失败重试；仅公开已发布角色 |
| 注册/登录 | 用户名密码、校验、跳转恢复 | 错误提示；过期 access 不影响公开账号接口 |
| 我的好友 | 继续对话、移除好友、不可用角色历史 | 下架或归档显示历史入口 |
| 个人空间/资料编辑 | 用户介绍与可访问角色、头像裁剪 | 所有权；刷新后恢复登录再加载私人列表 |
| 创作中心 | 我的角色、新建角色、已归档、资源入口 | 草稿和可见范围标签、恢复草稿、加载更多 |
| 角色编辑 | 名称、图片、公开介绍、私有设定、音色、发布方式 | 版本冲突提示、未保存离开确认、上传失败反馈 |
| 创作资源 | 角色知识文件、个人音色、后台任务、举报反馈 | 每5秒刷新任务；失败可重试或管理员核对 |
| 聊天弹窗 | 历史、语音气泡、输入、发送/停止、长期记忆 | 接近底部才自动滚动；历史音频按需加载 |
| Django admin | 用户、角色、资源、举报、任务及审计 | 管理权限控制；个人密钥在环境中配置 |

视觉沿用现有浅色卡片、柔和边框和紧凑操作布局。表单块必须随父容器收缩，不应再出现截图中子卡片超出外框的问题。主按钮表达当前动作，异常仅在实际操作失败时提示，不常驻“AI/语音未配置”文字。

可访问性保留控件标签、跳到主体链接、角色播放按钮名称、输入标签与状态文本。响应式优先保证320px宽度下输入、按钮和对话可操作；本轮尺寸测试属于浏览器模拟，不能替代手机触摸和系统权限测试。

## 4 用户总流程

### 4.1 普通用户

1. 游客浏览公开角色并按名字/公开介绍搜索。
2. 发起聊天时先登录；系统创建或复用唯一好友关系。
3. 输入文字发送；同一按钮从发送变为停止；生成时再点击即请求取消。
4. 回复文字流式展示，启用角色语音回复后合成并显示语音气泡。
5. 点击气泡播放；右键或更多菜单选择“转换成文字”，展示已保存的原回复。
6. 成功、失败、取消分别保存；重开时读取自己的历史。
7. 可查看编辑记忆，关闭后该会话不读取、不自动更新记忆。
8. 角色不可用后保留历史为只读；恢复可访问后继续原好友会话。

### 4.2 创作者

1. 创作中心新建角色，上传并裁剪头像与背景。
2. 填写公开介绍和私有AI设定；选一个音色或“仅文字”。
3. 保存私有草稿，自行预览；需要公开时选择发布及可见范围。
4. 如启用公开审核，公开发布进入 reviewing；管理员通过后进入 published，拒绝原因供作者查看。
5. 资源页关联角色上传 TXT/MD，任务完成后用于该角色回答。
6. 需要个人音色时上传已获授权的合格WAV；复刻成功后在角色音色列表中选择。
7. 编辑提交当前 version；冲突返回409，重新载入再决定修改。
8. 不再提供角色时归档；恢复进入 private/draft，历史与资源仍保留。

### 4.3 研发与验收流程

需求基线核对 → 范围和数据策略确认 → 模型与接口修改 → 备份和迁移 → 自动测试 → 真实服务调用 → 浏览器验收 → 文档同步 → 预发布配置 → 设备/供应商补验 → 发布与复盘。

每项任务必须有代码入口、验证方法和明确限制。外部验收失败先定位账号、模型、协议或设备原因，不能只增加“已配置”标识。

## 5 账号与个人资料

注册使用数据库事务创建 User 与 UserProfile。用户名最多150字；重复、空值及密码规则由账号接口校验。登录返回 access，refresh 放在 HttpOnly Cookie；access有效2小时，refresh有效7天。刷新轮换并拉黑旧刷新凭证，退出撤销刷新凭证。

公开账号接口不携带失效 access。私人接口遇到401只刷新一次，不能无限重试。创作中心、资源页、个人空间等待用户编号恢复再发送依赖登录的请求。

资料介绍最多500字。头像先验证再替换；更新成功后才处理旧头像。图片在浏览器裁剪，取消不替换原图。未实现账号注销产品流程，保持后续需求，不声称已经具备。

## 6 角色字段、发布与生命周期

| 字段/规则 | 当前约束 | 用途 |
|---|---|---|
| name | 1至50字 | 展示、搜索 |
| public_description | 最多200字；公开发布不能为空 | 对外介绍，不包含私有设定 |
| persona_prompt/profile兼容字段 | 最多100000字 | AI设定；只有作者编辑接口返回 |
| photo/background_image | JPEG/PNG/WebP，每张最多5MB，最多2000万像素 | 实际图片内容验证 |
| voice | 可空；仅可用预设或本人就绪音色 | 每个角色当前选择一个音色，可更换 |
| visibility | private、unlisted、public | 自己、已知链接可访问、公开发现 |
| status | draft、reviewing、rejected、published、archived | 草稿、待审核、拒绝、发布、归档 |
| version | 正整数，编辑/归档/恢复校验 | 防止覆盖并发修改 |
| moderation_reason | 最多500字 | 管理员拒绝原因，仅作者可见 |

新角色默认 private/draft。旧角色迁移保留原先公开发布状态，以免无故下架；旧介绍拆出公开摘要与私有设定，旧公开文本不会因迁移而被宣称“原本保密”。所有新公共列表仅返回公开介绍。

private角色仅作者访问；unlisted角色不进入发现页，但已知角色入口可访问，不能视为加密分享；public仅发布后进入发现。草稿、审核中、拒绝状态仅作者预览。归档阻止新生成，已有消息仍归会话用户所有。

“删除角色”产品语义已改为归档；恢复不自动公开。未实现定时物理清除，归档保留期限当前无限制，需后续明确容量与保留政策。

## 7 发现、好友与会话

首页按名字与公开介绍搜索，返回稳定排序公开角色。保留 offset 参数，后端支持游标兼容；客户端现有加载更多仍主要使用 offset。标签和推荐属于P2。

Friend具有(me, character)唯一约束。重复进入聊天复用同一关系，历史不复制。旧重复关系迁移时合并消息，保留全文；请求编号冲突解除重复编号而不丢消息。

移除好友是关系归档，重新访问同角色恢复原会话。一位好友目前对应一段历史和记忆；尚无 Conversation 多会话实体和切换UI，不把它列为当前已实现能力。

## 8 AI聊天、停止与历史

文字供应商通过 OpenAI 兼容接口独立配置，当前本机为 DeepSeek。AI系统提示使用角色私有设定和系统设定，记忆仅在会话开关开启时读取；最近成功历史限制10组、约24000字符参与上下文，数据库仍保存完整历史。

客户端每次发送 request_id。服务器先写pending消息并取得数据库 GenerationLease；同好友并发生成返回冲突。状态流转为pending、streaming以及completed/failed/cancelled。取消和失败的部分回复可见并保存其状态，不作为成功上下文。

SSE发送消息编号、知识来源元信息、文字片段、音频片段、语音警告、错误与完成标记。重复成功请求直接返回已保存回复，不再次调用模型；失败或取消允许同编号同内容重试，内容改变返回409。

同一个主按钮在空输入时不可发送、有文字时发送、生成时停止。取消通过共享数据库租约标记并通知本地任务；连接关闭也释放任务。租约150秒过期可恢复；跨进程实际高负载仍需部署压力验收。

AI最长生成90秒，TTS阶段最长30秒，模型单次请求45秒且SDK重试关闭；知识和嵌入请求有独立限制。get_time工具图最多8次步骤，避免无限工具循环。当前不是通用第三方工具市场。

历史每批10条，滚动去重按服务器消息编号；仅接近底部才跟随新消息。语音文件放private_storage，JWT校验会话所有者后下载，公共/media路径不提供消息语音。

## 9 语音输入、回复与音色

### 9.1 语音输入

浏览器VAD资源随安装依赖复制到本地，录音上传16kHz单声道、小端PCM16，最长60秒；完成一句后暂停采集，避免无意持续录音。关闭面板与组件卸载释放麦克风和计时器。识别先供用户确认，再进入输入框发送。

当前ASR适配DashScope任务协议，支持Gummy output.transcription及FunASR output.sentence，只接收最终片段并忽略心跳。当前账号 gummy-realtime-v1 调用返回 Model not exist，本地配置调整为实测成功的 fun-asr-realtime。此结论只针对本次账号调用，不宣称所有地区都不再提供Gummy。

本轮合成测试语音送入实际ASR识别成功；真实人的麦克风采集、授权拒绝、断网及手机录音还需设备验收。

### 9.2 语音回复

“角色语音回复”开关决定本次是否合成。成功后首先显示微信式语音气泡，不立即展开原文字；右键或更多按钮可转换/收起文字。这里的转换显示已保存的AI原回复，不再次调用ASR。

TTS失败保留全文并提示，部分损坏音频不当作成功语音。历史重开可以重新播放，加载使用私有端点。此版本TTS在全文生成后开始，未实现全双工电话或逐句低延迟播报。

### 9.3 预设音色

名称统一位于 backend/web/services/voice_catalog.py 的 VOICE_NAMES，说明位于 VOICE_DETAILS。更改中文展示名不改变供应商 voice_id。当前包括阳光男声、亲切女声、沉稳女声、青春女声、温柔男声、温柔女声、干练女声。可试听、选择、更换，一个角色选择一个音色；不同时叠加多个声线。

目录按配置TTS模型适配，非Flash模型不会直接展示Flash专用新增预设。个人音色只对拥有者显示，目标模型不一致不能选用。

### 9.4 个人音色复刻

资源页填写音色名字并确认样本授权。样本限制10至20秒、单声道、16位PCM WAV、至少16kHz、最多10MB，检查低音量和明显削波；每人最多10个个人音色。

配置VOICE_URL及TTS凭据，PUBLIC_BASE_URL必须是供应商能访问的公网HTTPS地址。后台任务为样本签发30分钟地址，创建、轮询复刻状态，就绪后清理样本；样本URL在任务结束后失效。

提交供应商前记录uncertain，进程异常时不能盲目再创建收费音色；管理员需核对供应商实际资源。安全查询可继续轮询，最多60次；失败任务通常最多尝试3次，不确定提交禁止用户直接重试。

删除在用音色返回409，先更换所有引用角色再删。云端删除成功后删除本地音色和样本。失败样本暂留私有目录用于重试，目前没有自动过期清扫器。

当前未配置复刻公网环境和授权人声样本，故真实创建/查询/删除仍待验收；不得把协议替身测试写成真实复刻成功。

## 10 角色知识库

P1支持UTF-8 TXT/Markdown，不含PDF/OCR。单文件最多1MB且正文最多20万字符，每角色最多20份。文件记录作者、角色、名称、SHA256、内容、索引状态和索引模式；同角色同内容不重复入库。

上传返回202和任务编号，worker按1000字符分片、200字符重叠。无嵌入配置时使用本地关键词检索；配置独立EMBEDDING_API_KEY/BASE_URL/MODEL后生成向量，结合词匹配与相似度；模型变化不混用旧向量，查询嵌入失败回退关键词。

仅检索当前角色关联、作者归属一致且就绪的资料，返回最多3个片段、每片段最多1200字符。参考文本作为非可信资料输入，不能覆盖系统规则。来源文件名、文档编号和片段位置保存于消息，刷新后仍展示。

上传原文件与原文管理只给作者；公开角色的聊天回答可能引用这些资料，因此上传时应按对该角色聊天用户可披露的信息选择内容。不承诺通过提示词完全阻止模型复述参考内容。

删除文档同时删除片段并取消未完成任务；与worker并发通过事务避免已删文档重新出现。现有老共享LanceDB演示表默认关闭，不是新角色隔离知识库的前置依赖。

## 11 长期记忆与后台任务

每个Friend有memory、memory_version和memory_enabled。用户查看、编辑、清空后保存；开关关闭后不读或更新，保留内容便于之后重新启用。最多5000字，提交version不符返回冲突。

MEMORY_AUTO_UPDATE默认false；开启后每10条成功对话安排持久化摘要任务。任务带当时version，手工修改/清除/关闭后旧任务不得覆盖。摘要使用MEMORY_MODEL或文字模型回退，最终摘要与原始对话分别存储。

BackgroundJob持久化kind、归属、目标编号、dedupe_key、payload、状态、尝试次数和可执行时间。run_jobs每秒检查，worker每20秒心跳；任务5分钟无进展可重新排队。条件UPDATE领取避免多个worker重复领取同任务。最长60次音色状态轮询是安全查询，不等同于60次复刻创建。

索引、摘要和音色操作不再依赖临时Python后台线程。停止worker后排队任务仍在；页面显示失败并允许有限重试。正式部署必须把worker作为独立守护服务启动。

## 12 管理、审核、举报与服务健康

现阶段使用Django admin管理基础实体，未新建独立配置控制台。供应商密钥、模型和部署参数在服务器环境中维护。配置修改后重启backend与worker；不从页面回显密钥。

REQUIRE_CHARACTER_REVIEW默认false。启用时提交public发布进入reviewing；staff检查公开内容，在admin改为published或rejected，填写moderation_reason。作者可查看结果并修改再提交。管理员角色修改递增version并记录审计。

普通用户可举报可访问角色，原因1至200字。同用户同角色未处理举报不重复创建。管理员处理pending/resolved/rejected和反馈文字，作者与举报者不因此获得他人消息权限。处理审计保留操作者、动作、目标及时间。

GET /api/capabilities/只判断配置，不探测供应商，每项verified保持false以免造成虚假可用承诺。GET /api/admin/health/仅staff可读，执行数据库ping、检查60秒worker心跳、队列状态计数，报告AI/ASR/TTS最近24小时实际成功时间和成功/失败次数。

健康观测最多保留1000条，不保存聊天正文和密钥；样本少时不能作为稳定成功率或SLA。嵌入与复刻通过配置、资源/任务状态诊断，尚无独立实际连通探测和统计面板。

## 14 技术架构与调用链

前端Vue3、Pinia、VueRouter、Vite；后端Django6、DRF、SimpleJWT；LangChain/LangGraph负责文本与工具；DashScope WebSocket负责语音；SQLite负责本地数据和任务。Python要求3.12及以上，旧README的3.8要求已纠正。

消息链：输入组件 → JWT API → 角色及会话权限 → request_id/GenerationLease → 最近历史与记忆 → 当前角色知识检索 → ChatGraph → SSE文字 → 可选TTS → 完整消息/音频/来源落库 → 必要时摘要任务。

知识链：资源页上传 → 归属/格式/hash检查 → Document和Job → run_jobs → 分片/可选嵌入 → 就绪 → 聊天检索 → 来源随消息保存。

复刻链：授权样本 → 私有文件及Job → 限时HTTPS样本地址 → 供应商创建 → 状态轮询 → 私有音色就绪 → 角色选择。不能使用DeepSeek文本密钥代替阿里云语音凭据。

## 17 数据权限与删除影响

角色原始设定、会话、记忆、音频、任务、原文档、个人音色按归属过滤。管理员具备明示管理权限；普通用户不能依靠猜编号跨用户访问。公开资料只包含展示字段。

| 操作 | 实际影响 | 恢复与清理 |
|---|---|---|
| 角色归档 | 阻止新对话生成，历史保留 | 可恢复为私有草稿，无自动物理清理 |
| 移除好友 | 不再出现在活跃好友列表 | 同角色重新建联恢复原Friend及消息 |
| 清空记忆 | 保存后清空、version递增 | 旧自动任务不可覆写；不会删除聊天 |
| 删除知识文件 | 文档及片段删除，任务取消 | 没有文档回收站，操作明确提示 |
| 删除个人音色 | 在用时拒绝；先云端再本地 | 失败可重试，不制造假删除成功 |
| 复刻样本结束 | 成功/删除后清理；地址30分钟到期 | 失败样本私有保留待处理 |

账号注销、自动保留期清扫、完整数据导出尚未提供，保留为后续独立需求。私人样本与消息音频不得映射到公开Nginx目录。
